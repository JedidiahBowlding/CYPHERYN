# ADR 010: Why no token exists

Status: accepted.

## Decision

Do not create a CYPHERYN token. No current requirement needs a proprietary asset rather than fiat billing, stablecoins, cryptographic identity, and off-chain reputation.

Any future token is a separate project requiring legal, securities, tax, AML/sanctions, governance, economic, manipulation, and independent smart-contract review. This architecture provides no token, sale, staking, wallet UI, or governance contract.
